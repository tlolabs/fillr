# FILLR 1.1.0

This release integrates the existing native macOS Chabot background planner,
renderer, and hardware profiling work. The collection engine and authenticated
update controls retain their existing contracts. Windows and Linux background
rendering are outside this feature.

The audit follow-up fixes native integer validation before narrowing conversion,
overflowing benchmark sample ranges, a prepared GPU job ignoring a newly requested
hardware-decode requirement, eager access to missing container-duration metadata,
and hardware reports accepting duplicate or missing panel identities. Regression
coverage exercises these failures without media processing or UI automation.

Workload fingerprinting now reads metadata once per unique standardized source
within each call. It still refreshes metadata between calls. A synthetic optimized
microbenchmark with 3,000 segment references to two placeholder files, 20 calls,
and three alternating runs per version measured median 0.805696 s before and
0.481579 s after (40.23% less elapsed time), with identical fingerprints. This is
not a full render-speed measurement.

## Verification and coverage

- 162 Rust tests passed; four opt-in performance tests were not run. The local
  loopback updater test required normal execution permission outside the sandbox.
- 134 selected Python tests and 109 weekly-delivery tests passed. These tests use
  mocks for publication; no release upload occurred.
- 42 selected Swift tests passed, covering preferences/update policy, folder and
  configuration concurrency, cancellation, planning, profile policy, fingerprint
  freshness, and native C-ABI input validation.
- Cargo formatting, Clippy with warnings denied, version/tag consistency, and the
  shared updater snapshot check passed.
- A fresh universal macOS package was built with Developer ID signing, Apple
  Accepted notarization, stapling, and Gatekeeper verification of the app extracted
  from the final ZIP. Default local-only automatic-update policy was retained.

Interactive/visual UI tests and media render/decoder integration tests were not
run in this task at the owner's direction. Historical test results are not current
qualification. Native Windows/Linux builds were not run locally. The macOS package
is **Build verified — community testing pending**; this task does not claim full
runtime or visual qualification and does not upload binary assets.

## Independent audit limitations

The requested sequence was Gemini 3.8 Flash High, Codex fixes, Copilot, then Codex
fixes. Neither external stage produced an accepted audit. The Gemini stage was
held at preflight because the same installed CLI's prior attempt reported the
requested `gemini-3.8-flash-high` unavailable and resolved a different default;
the unchanged blocker was not retried. The configured profile remains `gemini`;
no alternate model or provider was substituted.

Copilot ran against a fresh code-only snapshot with fallback disabled. Its
provider-default model identity was unreported. It returned no supported findings,
said it had not examined the patch in depth, and omitted the required review token;
the runner rejected the response as incomplete (exit 20). Its three actual checks
(71 pure/mock Python tests, version consistency, formatting) passed. Native Swift
checks were run separately by Codex. No external report certifies the final source.
